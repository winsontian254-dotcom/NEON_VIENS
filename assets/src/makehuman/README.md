# MakeHuman system assets (CC0)

The base human mesh (`base.obj`), its skeleton and skin weights (`rigs/`), the high-poly eyes and the brown eye texture (`eyes/`)
come from the MakeHuman community project (https://github.com/makehumancommunity/makehuman, `makehuman/data`).
Each file's header states: "This asset was explicitly released as CC0 in september 2020" (copyright holders at the time of the release:
Data Collection AB, Joel Palmius, Jonas Hauquier). The CC0 text is `LICENSE.CC0.md`. The Neon Veins human kit
(`tools/blender/build_humans.py`, `tools/blender/mh_import.py`) builds its head, hands and eyes from these files.
